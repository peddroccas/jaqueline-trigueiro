# Jaqueline Trigueiro — site

Site de página única da Jaqueline Trigueiro, designer de sobrancelhas e micropigmentadora na Ceilândia Sul (DF).

- **Stack:** Next.js (App Router) + Tailwind CSS v4, 100% estático.
- **Briefing e decisões de design:** [`docs/briefing.md`](docs/briefing.md)
- **Conteúdo (textos, serviços, contatos, mensagens do WhatsApp):** [`src/content/site.ts`](src/content/site.ts)

## Rodar localmente

```bash
npm install
npm run dev
```

Abra http://localhost:3000.
